# 数值分析考试讲义

按张铁、邵新慧《数值分析》（科学出版社 2022，ISBN 9787030718136）整理的个人复习站。记号、定理编号、例题编号和指定习题题面跟书走。正文是学习讲义，不是教材影印。指定习题默认只给题面，展开后才是详解。

书上的选学星号不改考试范围。范围以个人划记为准：三角为重点，未标记为选择性，划叉为不考。

## 页面

| 路径 | 内容 |
|---|---|
| `/` | 章节目录、进度、下一节 |
| `/read/ch1` … `/read/ch9` | 分节讲义。第 5 章无正文；第 9 章保留正文，但整章标记为不考 |
| `/formulas` | 公式卡片 |
| `/drill` | 易混点、证明提纲、指定习题。题面默认展开，详解要点「看详解」 |
| `/ai` | AI 视角：softmax 平移、条件数、Adam 的 ε、混合精度、量化 |

进度存在浏览器本地（`localStorage`），刷新不会丢。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:8080>。

```bash
npm run typecheck
npm run build
```

认证和数据库默认关闭，本地预览不需要配置。

## 内容放在哪

| 文件 | 作用 |
|---|---|
| `src/lib/content/lecture.json` | 各章正文 |
| `src/lib/content/formulas.ts` | 公式卡片 |
| `src/lib/content/exercises.ts` | 指定习题题面 |
| `src/lib/content/solutions.ts` | 46 道详解的入口 |
| `src/lib/content/solutions.json` | 详解正文，以及和书后简答不一致的说明 |
| `src/lib/content/proofs.ts` | 证明提纲 |
| `src/lib/content/plain.ts` | 大白话对照 |
| `src/lib/ai-track/` | AI 视角 |

## 技术栈

React 19、TanStack Start / Router、Tailwind CSS v4、KaTeX、Zustand。公式只用 `$` / `$$`。

## 仓库里没有的东西

- 教材 PDF，以及书后习题简答的原样抄录
- 对照草稿、页面截图
- 任何密钥

教材版权归科学出版社及作者。本仓库只供个人复习，不代替教材。详解是学习整理，不代替书后答案。
